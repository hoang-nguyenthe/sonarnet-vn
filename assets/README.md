# Cảnh Sentinel-1 dùng cho bản demo

`sentinel1_binh_thuan_20260912.png` là ảnh xem nhanh Sentinel-1 GRD thật ngoài
khơi Bình Thuận. Ứng dụng đã lấy cảnh này qua Copernicus Data Space Process API
vào ngày 16/09/2026. Tệp JSON kèm theo lưu mã sản phẩm, thời điểm chụp, vùng
quan sát và thông số dựng ảnh; không chứa OAuth credential.

Ảnh có vai trò minh chứng luồng tích hợp dữ liệu thật trong bản demo. Không dùng
làm dữ liệu huấn luyện, không gán nhãn phương tiện và không suy luận danh tính.
